РЕЛИЗ ДЛЯ ЯНДЕКС ИГР

В папке находятся два разных архива:

01 — Игра для загрузки.zip — архив игры. Загрузите его в поле сборки игры целиком, не распаковывая.
02 — Материалы Яндекс Игр.zip — готовая иконка, обложка, скриншоты и видео. Распакуйте его и выбирайте отдельные файлы для соответствующих полей каталога.

Внутри материалов:
• Иконка и обложка — отдельная папка, PNG 512×512 и 800×470.
• Скриншоты — 3 кадра для компьютера, 3 для телефона горизонтально и 3 для телефона вертикально. Для мобильной платформы в каталоге выбирайте только одну ориентацию и используйте все три снимка из соответствующей папки.
• Видео — отдельные MP4 для компьютера и обеих ориентаций телефона; это дополнительные материалы.
• Памятка для загрузки — повторяет порядок и состав файлов.

В игровом архиве структура папок оставлена технической: пути assets, data, js и styles нужны для работы игры и не должны переименовываться.

# 🕵️ Детективное судоку

**Детективное судоку** — логическая веб-игра, объединяющая механику судоку и детективное расследование.

Игрок изучает улики, восстанавливает расположение персонажей на плане особняка и постепенно раскрывает связанные между собой дела.

## 🎮 Как играть

В каждом деле необходимо:

- изучить материалы расследования;
- проанализировать улики;
- расставить персонажей на игровом поле;
- учитывать правило: один персонаж в строке и один в столбце;
- восстановить картину событий;
- сделать итоговый вывод по делу.

У каждого дела есть только **одно правильное решение**.

## 📁 Сюжет

Расследования объединены в главы.

Первая глава — **«Особняк Блэквуд»**.

Проходя дела, игрок открывает новые факты, знакомится с участниками событий и постепенно приближается к разгадке главной тайны особняка.

## ✨ Возможности

- сюжетные детективные дела;
- логические головоломки разной сложности;
- система улик и подсказок;
- автоматическое сохранение прогресса;
- материалы расследования и карта;
- адаптивный интерфейс для desktop и mobile;
- единое уникальное решение для каждого дела.

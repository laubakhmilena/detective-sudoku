# Детективное судоку

Кампания из 12 глав и 122 дел. Первая глава — расследование Ричарда Блэквуда и K-17, ещё 11 глав содержат по 10 дел. Интернет для игры не требуется.

## Запуск

1. Откройте `index.html` в современном Chrome или Edge.
2. Нажмите «Играть». Главы открываются последовательно.

Можно запустить локальный сервер: `python -m http.server 8000`, затем открыть `http://localhost:8000`. Для сохранения используйте один и тот же адрес и браузер. Сохранения находятся в localStorage браузера, в архив они не включены. При смене пути файла или адреса сервера браузер может использовать другое хранилище.

«Продолжить» возвращает к сохранённому делу. Выход в меню сохраняет ответы, ошибки, подсказки и активное время. Время отсутствия не учитывается. Сброс всех глав находится в настройках и требует подтверждения. Звук — короткий сигнал успешной проверки; переключатель сохраняется.

## Управление

- Сетки: выберите участника, затем клетку. В строке и столбце должен быть ровно один человек. Учитывайте помещения, блокирующие предметы и показания.
- Хронология и цепочки: добавляйте карточки по порядку. Нажатие звена позволяет исправить последовательность.
- Маршруты: выбирайте соединённые места, учитывая время и закрытые зоны.
- Документы: сравнивайте поля и отмечайте расхождения.
- Финал: укажите части версии и подтверждающие материалы.

## Сценарий и ресурсы

Редактируемые источники: `campaign/stories.js`, `campaign/engine.js`. Реестр используемых изображений: `assets/campaign/registry.json`.

## Проверки для разработчика

Данные и уникальность:

```
node tests/chapter1-data.test.mjs
node tests/chapter1-flow.test.mjs
node tests/campaign-data.test.mjs
```

Проверки интерфейса требуют Node.js, пакет `playwright` (`npm install`) и установленный Google Chrome:

```
node tests/campaign-browser.mjs
node tests/chapter1-browser.mjs
node tests/system-browser.mjs
```

Тест кампании проходит все 122 дела кликами, перезагружая страницу до проверки решения и после результата. Прямой вызов завершения дела не используется. Отдельный VM-тест проверяет внутренние инварианты и повторное завершение; он не подменяет браузерное прохождение.

Проверен Chromium/Chrome; Safari и Firefox отдельно не проверялись.


## Яндекс Игры

Интеграция находится в `platform.js`. SDK не включён в репозиторий: `/sdk.js` предоставляет платформа. Локально игра работает без SDK. Проверка интеграции: `node tests/sdk-browser.mjs` (имитация SDK). Поддерживаемый язык контента — русский.
